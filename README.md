# ClassBridge-AI

> Missed the class? Catch up smarter, not longer.

AI Class Recovery System — a full-stack web application that transforms
recorded online classes into structured, searchable, evidence-grounded
learning material and personalized catch-up paths.

## Tech Stack

- **Backend:** Java 17/21, Spring Boot, Spring Security, Maven
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MongoDB
- **AI:** Gemini API
- **Speech-to-Text:** Whisper / faster-whisper (Python)
- **Media Processing:** FFmpeg
